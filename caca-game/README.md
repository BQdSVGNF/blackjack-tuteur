# Bird Poop City (jeu local)
Ouvre `index.html` dans ton navigateur (double-clic) — aucune connexion requise.
- Souris : voler et viser (le cercle rouge = point d'impact)
- Clic / Espace : lâcher une crotte · R : recommencer
- Costards = 500 pts, voitures = 300, passants = 100. Enchaîne les touches pour le combo (x10 max) ; un raté casse le combo.
